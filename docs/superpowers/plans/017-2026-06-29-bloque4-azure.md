**Goal:** Crear, en `deploy/azure/` (**gitignored**), scripts PowerShell + Azure CLI idempotentes que aprovisionen y desplieguen la app en una suscripción Azure personal (~45 €/mes): 1 Resource Group con 1 App Service Plan Linux B1 (2 Web Apps: backend .NET 8 y frontend Next.js) + Azure Database for MySQL Flexible Server (Burstable B1ms).

**Architecture:** Despliegue **por código/zip** (sin Azure Container Registry, para abaratar y mantenerlo 100% local): backend vía `dotnet publish`→zip; frontend vía `next build` (standalone) con `NEXT_PUBLIC_API_URL` apuntando a la URL Azure del backend→zip. El esquema + seed se cargan en el MySQL Flexible con un cliente `mysql` dockerizado (sin dependencias locales). Toda la carpeta `deploy/azure/` se ignora en git; lo único versionado es la entrada en `.gitignore` y este plan (que documenta los scripts).

**Tech Stack:** PowerShell 7 (`pwsh`), Azure CLI (`az`), Azure App Service (Linux B1), Azure Database for MySQL Flexible Server (Burstable Standard_B1ms), `dotnet publish`, `pnpm build` (Next.js standalone del Bloque 0), `docker run mysql:8.0` como cliente.

**Prerrequisitos (ejecución, no en esta sesión):** `az` instalado y `az login` hecho; `az account set --subscription <id>`; .NET 8 SDK; Node + pnpm; Docker (para el cliente mysql). Imágenes/artefactos provienen de los Bloques 0/2/3.

**Contexto verificado del repo (no requiere relectura):**
- Backend lee `ConnectionStrings__DefaultConnection`; JWT de `Jwt:Secret/Issuer/Audience` (necesarios al arrancar). Healthcheck `/health`. **CORS `AllowAnyOrigin` incondicional** (`Program.cs` L131-137, `app.UseCors()` L177) → frontend y backend en hosts distintos funcionan sin ajuste CORS (auth por Bearer, no cookies). Swagger solo en Development.
- Frontend Next.js: `output: 'standalone'` (Bloque 0) → `.next/standalone/server.js`; `NEXT_PUBLIC_API_URL` se inlinea **en build**. Escucha en `PORT`/`HOSTNAME` (App Service inyecta `PORT`).
- `infra/docker/mysql/init.sql` (`USE bigschool;`) + `infra/docker/mysql/seed.sql` (`USE bigschool;`) cargan el esquema + demo.
- `.gitignore` raíz ya ignora `.env*`; **no** ignora `deploy/`. Hay que añadirlo.

**Estimación de coste (~45 €/mes, margen holgado):** App Service Plan Linux **B1** ~13 €/mes (las **2** Web Apps comparten el plan, sin coste extra) + MySQL Flexible **Burstable B1ms** ~12-15 €/mes (compute) + ~3 €/mes (20 GB storage) ≈ **28-31 €/mes**.

# deploy/azure/config.ps1 — variables de despliegue (GITIGNORED, NO commitear).
# Rellena con TUS valores antes de ejecutar 01-provision.ps1.

$AZ_LOCATION = "westeurope"            # alternativa: "spaincentral" (verificar disponibilidad B-series)
$AZ_RG       = "rg-bigschool-demo"
$AZ_PREFIX   = "bigschool-demo"        # base de nombres; debe dar nombres únicos en azurewebsites.net
$AZ_PLAN     = "$AZ_PREFIX-plan"
$AZ_BACKEND  = "$AZ_PREFIX-backend"    # https://<este>.azurewebsites.net
$AZ_FRONTEND = "$AZ_PREFIX-frontend"
$AZ_MYSQL    = "$AZ_PREFIX-mysql"      # debe ser único en mysql.database.azure.com

$MYSQL_ADMIN_USER     = "bsadmin"
$MYSQL_ADMIN_PASSWORD = "CHANGE-ME-Strong!2026"          # >=8, mayús/minús/dígito/símbolo
$MYSQL_DB             = "bigschool"

$JWT_SECRET             = "CHANGE-ME-AtLeast32CharsLongSecret!!"
$JWT_ISSUER             = "bigschool-tfm"
$JWT_AUDIENCE           = "bigschool-tfm"
$JWT_EXPIRATION_MINUTES = "60"

- [ ] **Step 2: Crear `deploy/azure/01-provision.ps1`**

```powershell
#Requires -Version 7
# Aprovisiona RG + MySQL Flexible + BD (esquema/seed) + App Service Plan + 2 Web Apps.
# Idempotencia: re-ejecutar tras un fallo es seguro (los create fallan "ya existe"; usar 99-teardown para empezar de cero).
$ErrorActionPreference = "Stop"
. "$PSScriptRoot/config.ps1"
$repo = Resolve-Path "$PSScriptRoot/../.."

Write-Host "==> Resource Group $AZ_RG"
az group create --name $AZ_RG --location $AZ_LOCATION --output none

Write-Host "==> MySQL Flexible Server (Burstable B1ms)"
az mysql flexible-server create `
  --resource-group $AZ_RG --name $AZ_MYSQL --location $AZ_LOCATION `
  --admin-user $MYSQL_ADMIN_USER --admin-password $MYSQL_ADMIN_PASSWORD `
  --sku-name Standard_B1ms --tier Burstable `
  --version 8.0.21 --storage-size 20 --public-access None --yes --output none

Write-Host "==> Reglas de firewall (Azure + tu IP)"
az mysql flexible-server firewall-rule create --resource-group $AZ_RG --name $AZ_MYSQL `
  --rule-name AllowAzureServices --start-ip-address 0.0.0.0 --end-ip-address 0.0.0.0 --output none
$myip = (Invoke-RestMethod -Uri "https://api.ipify.org")
az mysql flexible-server firewall-rule create --resource-group $AZ_RG --name $AZ_MYSQL `
  --rule-name AllowMyIP --start-ip-address $myip --end-ip-address $myip --output none

Write-Host "==> Base de datos $MYSQL_DB"
az mysql flexible-server db create --resource-group $AZ_RG --server-name $AZ_MYSQL --database-name $MYSQL_DB --output none

$MYSQL_HOST = "$AZ_MYSQL.mysql.database.azure.com"
Write-Host "==> Cargar init.sql + seed.sql en $MYSQL_HOST (cliente mysql dockerizado)"
Get-Content "$repo/infra/docker/mysql/init.sql", "$repo/infra/docker/mysql/seed.sql" -Raw |
  docker run --rm -i mysql:8.0 mysql -h $MYSQL_HOST -u $MYSQL_ADMIN_USER -p"$MYSQL_ADMIN_PASSWORD" --ssl-mode=REQUIRED $MYSQL_DB

Write-Host "==> App Service Plan Linux B1"
az appservice plan create --resource-group $AZ_RG --name $AZ_PLAN --location $AZ_LOCATION --is-linux --sku B1 --output none

Write-Host "==> Web App backend (.NET 8)"
az webapp create --resource-group $AZ_RG --plan $AZ_PLAN --name $AZ_BACKEND --runtime "DOTNETCORE:8.0" --output none
az webapp config appsettings set --resource-group $AZ_RG --name $AZ_BACKEND --output none --settings `
  "ConnectionStrings__DefaultConnection=Server=$MYSQL_HOST;Port=3306;Database=$MYSQL_DB;User=$MYSQL_ADMIN_USER;Password=$MYSQL_ADMIN_PASSWORD;SslMode=Required;" `
  "Jwt__Secret=$JWT_SECRET" "Jwt__Issuer=$JWT_ISSUER" "Jwt__Audience=$JWT_AUDIENCE" "Jwt__ExpirationMinutes=$JWT_EXPIRATION_MINUTES" `
  "ASPNETCORE_ENVIRONMENT=Production"

Write-Host "==> Web App frontend (Node 20)"
az webapp create --resource-group $AZ_RG --plan $AZ_PLAN --name $AZ_FRONTEND --runtime "NODE:20-lts" --output none
az webapp config set --resource-group $AZ_RG --name $AZ_FRONTEND --startup-file "node server.js" --output none
az webapp config appsettings set --resource-group $AZ_RG --name $AZ_FRONTEND --output none --settings "HOSTNAME=0.0.0.0"

Write-Host ""
Write-Host "Provisión completa:"
Write-Host "  Backend : https://$AZ_BACKEND.azurewebsites.net  (/health)"
Write-Host "  Frontend: https://$AZ_FRONTEND.azurewebsites.net"
Write-Host "Siguiente: ./02-deploy.ps1"
```

- [ ] **Step 3: Crear `deploy/azure/02-deploy.ps1`**

```powershell
#Requires -Version 7
# Compila y despliega (zip) backend y frontend a las Web Apps creadas por 01-provision.ps1.
$ErrorActionPreference = "Stop"
. "$PSScriptRoot/config.ps1"
$repo = Resolve-Path "$PSScriptRoot/../.."
$tmp = Join-Path ([System.IO.Path]::GetTempPath()) "bigschool-deploy"
New-Item -ItemType Directory -Force -Path $tmp | Out-Null

# ---- Backend: dotnet publish -> zip -> deploy ----
Write-Host "==> Build backend (dotnet publish)"
$beOut = Join-Path $tmp "backend"
Remove-Item -Recurse -Force $beOut -ErrorAction SilentlyContinue
dotnet publish "$repo/src/backend/src/BigSchool.WebApi/BigSchool.WebApi.csproj" -c Release -o $beOut
$beZip = Join-Path $tmp "backend.zip"
Remove-Item -Force $beZip -ErrorAction SilentlyContinue
Compress-Archive -Path "$beOut/*" -DestinationPath $beZip
Write-Host "==> Deploy backend (zip)"
az webapp deploy --resource-group $AZ_RG --name $AZ_BACKEND --type zip --src-path $beZip --output none

# ---- Frontend: next build (standalone) con la URL Azure del backend -> zip -> deploy ----
Write-Host "==> Build frontend (next build standalone)"
$apiUrl = "https://$AZ_BACKEND.azurewebsites.net/api/v1"
Push-Location "$repo/src/frontend-web"
$env:NEXT_PUBLIC_API_URL = $apiUrl
pnpm install --frozen-lockfile
pnpm build
Pop-Location

Write-Host "==> Ensamblar salida standalone"
$feOut = Join-Path $tmp "frontend"
Remove-Item -Recurse -Force $feOut -ErrorAction SilentlyContinue
New-Item -ItemType Directory -Force -Path "$feOut/.next" | Out-Null
Copy-Item -Recurse "$repo/src/frontend-web/.next/standalone/*" $feOut
Copy-Item -Recurse "$repo/src/frontend-web/.next/static" "$feOut/.next/static"
if (Test-Path "$repo/src/frontend-web/public") { Copy-Item -Recurse "$repo/src/frontend-web/public" "$feOut/public" }
$feZip = Join-Path $tmp "frontend.zip"
Remove-Item -Force $feZip -ErrorAction SilentlyContinue
Compress-Archive -Path "$feOut/*" -DestinationPath $feZip
Write-Host "==> Deploy frontend (zip)"
az webapp deploy --resource-group $AZ_RG --name $AZ_FRONTEND --type zip --src-path $feZip --output none

Write-Host ""
Write-Host "Despliegue completo:"
Write-Host "  Frontend: https://$AZ_FRONTEND.azurewebsites.net"
Write-Host "  Backend : https://$AZ_BACKEND.azurewebsites.net/health"
```
